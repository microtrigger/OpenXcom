# OpenXcom with experimental semantic MCP control

OpenXcom runs X-COM: UFO Defense and Terror from the Deep using separately supplied original game data.

See [build, use, coverage and known limits](docs/mcp-player-interface/README.md).
`mcp-player-interface` contains the latest tested snapshot; `wip/named-button-v21e` and `wip/research-v22` retain unfinished work.
