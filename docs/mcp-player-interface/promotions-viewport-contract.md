# Promotions: read-only three-cell current viewport

This increment extends the title/headings slice with `rows: [{"cells": [string|null, string|null, string|null]}]`. Values are current painted TextList cells in current viewport order: names, shown rank captions and shown base captions, without reconstructing those values from models. Genuine empty strings and duplicate/indented captions are preserved. Null means unavailable, not empty. No soldier/base IDs, indices, handles, selected state, total count, offscreen report, rank enums, promotion flags or new actions are exposed.

The separate Promotion-only helper defaults off. It does not enable legacy outfitting or modify Commendation/Psi projection defaults. Reading never calls `Soldier::isPromoted()` or traverses bases/soldiers; the native constructor already consumed promotion flags while constructing its ordinary report. The unchanged inherited dispatch refuses semantic commands. Existing global cursor-motion policy is independent. OK remains visible but unsupported, and no scroll/row capability is added.

Native geometry is list288x128, columns114/90/84 with margin8. Cell allocations intersect the viewport as114/90/76px strips; the final8px overhang does not null a current logical base caption. Wholly horizontally offscreen cells are null. Rows require their full actual ordinary row-advance strip in the viewport; stock height9 plus spacing−1 advances8px, excluding the spare bottom allocation row. Partial vertical rows and wholly offscreen rows are omitted.

Content-independent invariants validate margin/cumulative column position, column width, actual draw y, equal allocated cell heights, positive allocation/advance and spacing at least−1 for every drawn row before omission. Arbitrary same-list overlap refuses rather than leaking covered text. Captured cell/list identity, revisions, geometry, current destination paint/clip, active/top/modal authority and actual later-widget/FPS occlusion remain required. Dirty/stale captures may refuse the whole projection; clean hidden cells must not export cached captions. Cosmetic cursor overlap is not a readability gate.

No glyph, ink, measured caption fit or completeness requirement is added. Long/multiline/missing-glyph captions retain current logical strings when the structural viewport is admitted; this is not a claim every character is pixel-visible. Limits are independent resource bounds: list at most640x400,128 admitted rows (overflow refusal),1024 UTF-8 bytes per cell (otherwise null, never truncation). Existing total9000-byte/conservative ASCII30000 payload bounds remain fail-closed.

Qualification uses native widgets/extracted constructor/provider with explicit domain/render seams, same-object valid3-column default-off→enable→fresh-paint, privacy sentinels, stock clipping/row geometry, stale/ABA/overlap, unchanged constructor flags and bounded baseline Commendation/Psi/legacy parity. Exact executed coverage and gaps are recorded separately. No tactical/live applicability, full report completeness, new actions or historical transport/safety resolution is claimed.
