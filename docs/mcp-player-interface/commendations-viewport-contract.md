# Commendations: read-only current viewport

This increment extends the title/OK contract with `rows: [{"cells": [string|null, string|null]}]`. The only action remains `close_commendations` with empty arguments, invoking the ordinary pop-only callback. No row selection or scrolling capability is added. Constructor `makeOld()` effects precede MCP acknowledgment; neither observation nor acknowledgment creates an award. The next state need not be Geoscape.

Each row contains exactly two current painted Text widget values, in current viewport order. Genuine empty strings and indentation are preserved. Null means an unavailable cell, not an empty value. No persistent identity, row index, handle, selected state, total count, diary/statistics/criteria, or model reconstruction is exposed. An empty viewport is not an exhaustive report.

The helper is explicitly Commendation-only and disabled by default. Existing Psi and legacy list projections are unchanged. The native list uses width288, columns204/84, margin8: the second cell's allocation extends8px past the right edge. Horizontal allocation intersection admits its76px visible strip without measuring glyphs or text fit. Rows require their full ordinary row-advance strip within the viewport. Stock small-font allocation height9 plus spacing−1 advances8px; the spare bottom allocation row is excluded from the observation strip. The full logical caption is retained without inspecting glyphs. Native margin/column positions, column widths, equal cell allocation heights and native row spacing (at least −1) are checked before omission, preventing same-list later-cell overlap without examining text or glyphs. Wholly offscreen cells contribute null and wholly offscreen rows are omitted. Long/multiline/missing-glyph captions and erased ink do not themselves invalidate logical text. This is not a promise that every returned character is pixel-visible.

Current list/cell identity, geometry, presentation/text/list revisions, paint destination, clip, active/top/modal authority and actual later-widget/FPS occlusion remain required. Pointer overlap alone is not an observation gate. Stale or dirty captures can refuse the entire provider, including never-painted dirty hidden cells; clean hidden cells never export cached text. No redraw or freshness guard is relaxed to force availability.

Resource bounds are independent of visual fit: list at most640x400, at most128 admitted viewport rows; each cell at most1024 UTF-8 bytes, otherwise null (never truncated). Existing provider total payload bounds9000 bytes and conservative ASCII budget30000 remain fail-closed. These bounds do not authorize hidden enumeration.

Qualification uses native widget/constructor/provider extraction with explicit domain/render seams, plus strict Python DTO tests. Privacy coverage includes partial horizontal clipping, hidden/offscreen sentinels, stale/ABA, wrong destination, actual overlays, current neighboring-row association, and paired same-object default-off/enable/repaint behavior. Exact terminal results and any gaps belong to the separate private qualification, not a claim of live or full-game coverage. Existing broader transport/safety qualification remains open.
